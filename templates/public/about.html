About DSG Bank

DSG Bank is a demo digital banking platform built to showcase a full-stack, production-style architecture: secure authentication, role-based dashboards, a real transaction engine, loan and card management, and administrative oversight — all built with Flask, MySQL, HTML, CSS and JavaScript.

This is an educational / portfolio project and does not process real money or real customer financial data.
